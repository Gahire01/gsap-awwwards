# GSAP Awwwards Website

An interactive, animation-driven website built with **React 19, Tailwind CSS 4, and GSAP 3**.
Focused on smooth scroll experiences, pinned sections, and responsive design across all devices.

Built by **[Gahire Abdilillah](https://github.com/Gahire01)**

## 🎨 About

This project is a showcase of modern frontend animation techniques using GSAP's ScrollTrigger and SplitText.
Every section is designed to feel alive — from character reveals to pinned scroll sequences, all while staying fully responsive.

---

## 🚀 Features

- **Advanced GSAP Animations** — Smooth, performant scroll-driven animations
- **Pinned Scroll Sections** — Sections that lock and animate on scroll
- **Text Splitting** — Character & word reveals with GSAP SplitText
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Dynamic Sections** — Hero, Benefits, Flavors, Nutrition, Testimonials, Message, Footer
- **Interactive Slider** — Flavor gallery with horizontal scroll
- **Multimedia Gallery** — Integrated images and video backgrounds
- **Clean Navigation** — Fixed interactive navbar

## 📦 Getting Started

### Prerequisites

- Node.js **v18 or higher**
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Gahire01/gsap-awwwards.git
cd gsap-awwwards

# Install dependencies
npm install

# Start the dev server
npm run dev
